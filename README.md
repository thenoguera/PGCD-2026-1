# Tecnologias e Soluções de Big Data

Este repositório reúne os notebooks, códigos e bases de dados utilizados nas aulas da disciplina **Tecnologias e Soluções de Big Data**, ministrada pelo **Prof. Rodrigo Ramos Nogueira, Msc**.

O objetivo do material é apresentar, de forma prática e progressiva, conceitos fundamentais de Big Data, manipulação de dados, computação paralela e distribuída, MapReduce, processamento com Python e análise exploratória de diferentes tipos de bases de dados.

## Sobre a disciplina

A disciplina aborda tecnologias e soluções utilizadas para lidar com dados em escala, considerando desde a leitura e exploração inicial de arquivos CSV até conceitos associados ao processamento distribuído.

Ao longo das aulas, os estudantes terão contato com:

- introdução ao Big Data;
- manipulação de dados com Python e Pandas;
- exploração e visualização de dados com Matplotlib;
- análise de bases textuais;
- conceitos de volume, variedade e velocidade dos dados;
- computação paralela e distribuída;
- introdução ao modelo MapReduce;
- preparação para o uso de tecnologias como NoSQL, Hadoop, Spark, Data Lakes e computação em nuvem.
